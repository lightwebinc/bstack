# Contributing

Issues and pull requests are welcome in every repository of the bstack
family.

- Open an issue before anything larger than a small fix, so the approach is
  agreed before the work.
- Keep a pull request to one change, and run the repository's checks first
  (its README or Makefile names them). CI runs the same checks.
- Record formats and protocols are specified in each repository's `docs/`. A
  change to one starts with the specification, and a frozen record format
  does not change.
- Documentation travels with the change, in the same pull request.
- By contributing you agree that your contribution is licensed under the
  Apache License 2.0, as section 5 of the license states.

Report vulnerabilities privately, as [SECURITY.md](SECURITY.md) describes.
